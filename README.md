# Energy Consumption Analysis & Optimization System

A cloud-based web application for analyzing electricity consumption and identifying potential energy-saving opportunities.

## Project Type

College Minor Project

## Objective

The system allows business users to upload electricity bills and electricity consumption data, analyze consumption patterns, and receive basic rule-based energy-saving recommendations.
